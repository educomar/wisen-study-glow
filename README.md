# Wisen Launchpad

Build the landing page with the Hero section and Footer for Wisen, cloning the exact aesthetic, background styling, and light/dark mode experience of studyybuddyai.com.

Logos:
Use the two attached logo files:
- Light mode logo: Use the attached image with dark lettering (IMG_4635.PNG), transparent background.
- Dark mode logo: Use the attached image with white lettering (IMG_4636.PNG), transparent background.
Switch the logo dynamically based on the active theme in both the navigation bar and the footer.

Hero Section:
- Headline:
  Study smarter.
  Remember longer.
- Subheadline:
  Turn your medical study time into focused practice, clearer understanding, and lasting knowledge.
- Primary CTA:
  Get started
- Visuals & interactions mirroring studyybuddyai.com:
  - Ambient glowing background gradients and styling matching studyybuddyai.com in both light and dark themes.
  - Working light/dark mode toggle button in the header.
  - An interactive USMLE-style cardiology clinical vignette question card mockup (just like on studyybuddyai.com) with question vignette, multiple choice options, AI explanation badge, and stats tags (+15% cardiology accuracy, etc.).
  - Animated marquee ticker below the hero cycling through medical specialties (Cardiology · Pharmacology · Pathology · Microbiology · Surgery · Anatomy).

Footer:
- Brand: Wisen (using the appropriate logo for current theme)
- Tagline: Study smarter. Remember longer.
- Columns:
  - Product: How it works, Question Bank, Wisen AI, Features
  - Resources: FAQ, Help, Contact
  - Company: About, Founder
  - Legal: Privacy Policy, Terms of Service
- Bottom bar:
  © 2026 Wisen. Built for medical students.
